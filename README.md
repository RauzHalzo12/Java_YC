# Snake (Змейка)

Терминальная игра Змейка на Python (`curses`).

Запуск:

```bash
python3 snake.py
```

Управление: стрелки или WASD. P — пауза, Q или Esc — выход.

Параметры:

```bash
python3 snake.py --width 60 --height 25 --speed 12
```

Для быстрой проверки без ввода используйте демо-режим (автопилот):

```bash
python3 snake.py --demo-steps 200
```
